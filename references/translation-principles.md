# 信达雅：可执行翻译原则

> 默认用于外语 → 简体中文，目标语言和地区仍以用户要求为准。这里的“雅”解释为风格恰当，而不是一律古雅。

## 一、决策顺序

1. **守住事实与语义边界（信）**：事实、施事受事、逻辑、否定、模态、条件、范围、时间、引述、证据等级、数量不能漂移。
2. **达成交际效果（达）**：调整语序、结构、指代、词性以使中文自然；翻译不是逐词替换。
3. **实现文体对应（雅）**：技术语言精准、口语真切、正式语体克制、文学语言尊重节奏与意象。
4. **无法兼顾时**：选择不会造成重大误解的译法；影响含义的无解歧义附简短译注，避免无根据“补全”。

## 二、信的检核点

| 要素 | 必须检查 | 典型误译 |
| --- | --- | --- |
| 数量与范围 | all / some / only / at least / up to / less than | `not all` → `都不` |
| 否定 | 否定词的作用域、双重否定 | `not necessarily` → `一定` |
| 模态 | may / could / should / must / shall 的具体语用 | `may` → `必须` |
| 因果证据 | association / correlation / causation / suggest / prove | `associated` → `导致` |
| 条件例外 | unless / except / provided that / subject to | 省略例外条件 |
| 时间与体 | already / still / before / after / ongoing | 完成与尚未完成混淆 |
| 主体归属 | 主语、代词、引用来源、相对句 | 把 A 的观点写成 B 的事实 |
| 文化语用 | 婉拒、讽刺、恭维、威胁、客套 | 只按字面解释 |

## 三、达的操作

- **转换句法**：把冗长关系从句、名词化结构转换成清晰的汉语句子；可以分句，不可分离必要修饰关系。
- **转换视角**：英语被动不必始终有“被”；必要时突出结果或动作，而不改变责任归属。
- **维护话题链**：同一段落里前后指代自然，不能为了简短省掉承载歧义的主语。
- **避免翻译腔**：慎用“进行一个”“有能力去”“其是”“被使用在”等直译式结构。
- **不过度精简**：论证性的重复、人物口头禅和修辞排比可能是信息本身。

## 四、雅的尺度

| 文体 | 优先事项 | 避免 |
| --- | --- | --- |
| 技术说明 | 可操作、术语稳定 | 诗化语言、含混动词 |
| 学术论文 | 准确、克制、保留证据等级 | 将可能性改为确定性 |
| 法律合同 | 定义、义务、例外的严格一致 | 自作主张“通俗化”改变法效 |
| 商务报告 | 逻辑、数据、简练 | 不必要口号化 |
| 文学创作 | 作者声音、意象、节奏 | 把一切统一“修辞优美” |
| 日常对话 | 口吻、情绪、含蓄度 | 公文化、抹除情绪 |

## 五、翻译策略选择

- **直译**：形义与中文自然表达吻合时采用。
- **意译**：字面译法破坏真实意思或自然度时采用。
- **词性转换**：如 nominalization → 汉语动词性表达。
- **显化/隐化**：可补少量语法或指代信息；不能补出无根据事实。
- **音译/借词**：没有稳定译名的专有名词、品牌、产品生态名词。
- **注释**：双关、文化专名或关键歧义不能在一条自然译文中两全时。
- **创译**：仅在用户明确要求广告本地化、传播效果重构等情形启用。

## 六、重要对比例

1. `Not all models are reliable.` → `并非所有模型都可靠。`，不是“所有模型都不可靠”。
2. `We found no evidence that it works.` → `我们没有发现证据表明它有效。`，不是“已经证明它无效”。
3. `The result may indicate a correlation.` → `这一结果可能提示存在相关性。`，不是“证明有因果关系”。
4. `He broke the ice.` → 在社交语境中 `他打破了僵局。`；实际凿冰语境应按字面翻译。
5. `This is a non-trivial problem.` → 日常技术语境 `这个问题并不简单。`；数学/理论语境中 `非平凡` 可能是专门术语。
6. `I couldn't agree more.` → `我完全赞同。`，不是“不能同意更多”。

## 七、翻译与邻近任务边界

- 翻译：传达全部原意，表达形式可变。
- 校对：修正译文或原文中的错误，必须区分修正与原文事实。
- 润色：不改变原意的语言优化。
- 改写：允许重新组织与扩展，只在用户明确要求时做。
- 摘要：可删减；不得替代完整翻译。
- 注解：补充背景，须与译文分开。
- 创译：针对营销/受众效果进行更广泛重构，非默认。
