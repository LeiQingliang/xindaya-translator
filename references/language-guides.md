# 源语言差异：只使用当前文本相关的提示

这些提示用于定位易错点，不是完整语法手册或语言支持清单。可处理的语言与质量取决于宿主模型及实际输入；不根据本文件列出的语言数量宣称“已支持”或“已验证”。

## 先做的判断

识别全文与局部混合语言，区分自然语言、代码和专名。依据句法与上下文确定施事、受事、否定范围、时体和礼貌关系；原文未提供的性别、人数、关系不要凭空补齐。罕见语言、方言、古语或受损文字无法可靠判读时，保留疑义并说明具体缺口。

## 常见易错机制

| 语言 / 场景 | 需要核对的内容 |
| --- | --- |
| 英语 | 否定作用域、情态、名词化、被动主体和长从句。`not all` 是“并非全部”；`no evidence` 不等于已证明不存在。`actually`、`eventually` 不按相似词形猜译。 |
| 日语 | 省略主语、授受关系、敬语、否定疑问和汉字同形异义。`手紙` 是“信件”；`結構です`、`大丈夫です` 可能是接受或婉拒，需看上下文；`よろしくお願いします` 不固定成同一句套话。 |
| 韩语 | 主语省略、敬语等级、句尾与社交距离。`괜찮아요` 可能是“没关系/可以/不用了”；亲属式称谓不必总按字面译作兄姐。 |
| 法语 | 虚拟式、时体、代词所指及礼貌单复数。`actuellement` 常为“目前”；`vous` 不足以单独确定一个人还是多人。 |
| 德语 | 复合名词、格关系、分离动词、句末谓语、虚拟式与间接引语。`bekommen` 通常为“得到/收到”，不是英文 become。 |
| 西班牙语 | 主语省略、虚拟式、时体及欧洲/拉美地区词义。`actualmente` 是“目前”；`embarazada` 是“怀孕的”。尊称按语境处理。 |
| 葡萄牙语 / 意大利语 | 地区差异、主语省略、动词变位、虚拟式及代词指向。不要把相似英语词义直接移入。 |
| 俄语及其他斯拉夫语言 | 格、体、性数、否定与信息焦点。不要仅凭词序判断主客体；不要因文字相似把乌克兰语等当作俄语。`да нет` 等组合按语用理解。 |
| 阿拉伯语 | 标准语/方言、未标元音的歧义、词形与性数、右至左文字、数字字形和固定文化表达。未知专名与宗教术语不要猜成确定译名。 |
| 印地语 / 乌尔都语等南亚语言 | 后置词、体貌、敬语及上下文；不同文字系统不能依赖相似拉丁转写猜译。 |
| 泰语 | 无显式空格的分词、礼貌助词、称谓及省略主语；不要逐字符对应。 |
| 越南语 | 称谓同时表达指代与社交关系。`anh/em/chị/cô` 等应依据双方关系，不机械固定为一个汉语亲属称谓。 |
| 印尼语 / 马来语 | 词缀、重叠词、语态、口语缩略和地区借词；语言接近不意味着地区词义完全相同。 |
| 土耳其语 | 黏着词形、条件及传闻/证据性标记；中文表达应保留“据说”等信息来源强度。 |
| 其他语言 | 先判断其实际句法和语境，再选译法；不要把“同语系”当作可直接替换词汇的依据。 |

## 繁体中文与地区用语

字形转换与词汇本地化分开处理：用户只要求简体字时，不自动改写地区措辞；要求中国大陆本地化时，可在相同语境下使用“软件”“内存”等常见词。人名、地名、法律名称、作品题名及文化背景不要盲目替换；以任务要求和已确认专名为准。

## 混合语言、称谓和专名

- 同一段可以有多个源语言；不要把引文或借词一律当作整篇语言。
- 姓名、机构、品牌、项目、代码和参数按用途保护，参见 [术语治理](terminology-policy.md)。
- 汉语无法自然表现的敬语或语法性别，可通过称谓、语气或上下文体现；不能为每处差异添加长注释。
- 文学双关、方言人物声音与文化意象按 [翻译原则](translation-principles.md) 选择策略；无法兼顾时保留主要意义，并仅在需要时说明取舍。
